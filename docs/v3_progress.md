**Native call containment update:** stdout and stderr are drained concurrently
under one default-or-declared byte ceiling, removing pipe-fill deadlocks and
unbounded response capture. Overflow terminates the process tree, yields a
payload-free `native_capsule_output_limit` receipt, and does not invalidate the
compiled-runner cache. Every native runner now also has mandatory 30-second
wall/CPU and 512-MiB memory defaults when declarations are absent. First-time
compiler/linker trees are contained under a separate hard 60-second deadline,
and the canonical v1 receipts identify the source of each
wall/CPU/memory/output limit.

**Native data boundary update:** live C/C++/Rust/Zig capsule inputs accept
bounded borrowed UTF-8 strings through a read-only pointer-length ABI and
fixed-byte-length mutable UTF-8 `&mut str` through a mutable pair, plus bounded
resizable UTF-8 `&mut String` through pointer, mutable length, and immutable
16-MiB capacity. Private
request framing is safe for NUL/newline bytes and no pointer can outlive the
call. Mutable inputs must be direct variables; aggregate resizable capacity is
limited to 64 MiB before compiler lookup, and copy-back is withheld until the
full response preserves required fixed lengths, stays within resizable capacity,
and validates as UTF-8.
`borrowed_input_bytes` receipts omit payload contents.
C/C++/Rust/Zig owned outputs cover twelve reviewed numeric layouts, including
full-range `Vec[u64]` and 64-bit-host-range `Vec[usize]`, plus UTF-8 `str`.
Typed descriptors, copy-before-free, exact unsigned/integer checks, width-aware float round-trip text,
non-finite rejection, and byte-accounted receipts gate interpreter exposure.
Exactly one owned `Vec[Record]` is also live when `Record` passes the existing
pointer-free scalar-leaf `@repr(C)` review. ABI-sized limits, exact typed
descriptors/free exports, complete record copy-before-free, leaf-count framing,
atomic nested reconstruction, and recursive tag restoration apply; record
vectors remain non-artifacts and are not yet pipeline inputs.
Immutable `&[Record]` inputs now cross the same four native languages as
runner-owned typed arrays. Parent validation preserves record boundaries and
every scalar leaf before flattening; child reconstruction requires complete
leaf groups. Per-input and cumulative aggregate reservations stay below 64 MiB
by reviewed ABI size, mutable record slices remain blocked, and receipts record
only borrowed ABI bytes.

**Pipeline fan-in update:** a stage may map one ordered read binding to each
declared input while retaining exactly one atomic output target. Graph planning
derives every producer/root edge, waits for all inputs, and reports the ordered
`sources` list. Binding-count/type errors and missing roots reject before native
dispatch.

**Pipeline resource-admission update:** optional run-wide CPU and memory
ceilings now require enforceable declarations on every stage. The scheduler
admits only when the declared CPU sum and sequential peak-memory declaration
fit, records both plans in `forgentex.pipeline_budget.v1`, and otherwise
dispatches no stage.

**Pipeline cancellation update:** library callers may share a cancellation
token checked before dispatch and before target commit; the CLI provides
deterministic `--stop-after-stages`. Cancelled runs preserve committed state,
withhold an externally cancelled pending output, and emit
`forgentex.pipeline_cancellation.v1`. Active native children remain governed by
their existing containment deadline rather than being interrupted.

**Pipeline numeric-boundary update:** immutable pipeline handoff now covers all
eleven native-reviewed numeric layouts. Integer producers, including
full-range `u64` and host-width `isize`, are range-checked and receipted
over canonical little-endian bytes before commit. Finite `f32`/`f64` producers
use exact little-endian IEEE-754 bits, with width checks and signed-zero
preservation. Matching read-only slice consumers receive a fresh bounded copy.
An exclusive `update` binding may now pass a reviewed vector to a matching
fixed-length mutable slice: validated copy-back and the stage's distinct target
commit atomically, with before/after hashes and rollback on denial,
cancellation, or budget exhaustion. General mutable native calls and sequential
share versions remain unsupported outside that pipeline transaction.

**Atomic native result update:** multiple logical scalar values use one named
`@repr(C)` result struct and therefore validate and commit as one value. The
`dual_output_c` example proves result/status fields without claiming an
independent multi-output ABI or multiple owned returns.

**Application-shell update:** `[application]` requires an exact major/minor
Forgentex compatibility line and fixes the package entry, `hosted_io` runtime,
filesystem effects, and cumulative byte ceilings. `fgx app-run` rejects a
mismatched toolchain before dispatch and decodes each positional argument from
the entry signature's supported scalar or portable-path type, then combines
those declarations with canonical package-relative `[permissions]` roots,
symlink-aware containment, supply-chain preflight, and
`forgentex.application_run.v1`. Successful runs report declared result types
with JSON-native values; completed failures report stable code, phase, and
message fields, and pre-dispatch JSON failures use
`forgentex.application_error.v1`. The upgraded `scoped-copy` example reads an
arbitrary file as a bounded `Vec[u8]` and atomically publishes a complete new
declared artifact with exact hash evidence. Tests cover non-UTF-8 bytes, out-of-root access, traversal, read
and write budget exhaustion, static byte-vector typing, existing-target
refusal, temporary-file cleanup, typed argument syntax/ranges, unsupported
argument and result shapes, structured result/error JSON, networking, and async
execution. Networking and async execution remain.

**Typed-path/directory update:** `core.path` now owns an immutable, strict
portable `Path` contract with parsing, joining, parent/name/extension, string,
and component-prefix operations. `core_io_list_dir` returns one sorted
all-or-error `Vec[DirEntry]`; normalized path bytes consume the read budget and
entries consume an explicit cumulative `max_directory_entries` limit. The
`directory-inventory` app and denial tests cover traversal, backslashes,
absolute/reserved paths, static `Path` separation, missing limits, entry
exhaustion, and path-byte exhaustion.

**Serialization update:** source-backed `core.serialize` now exposes a strict
16-MiB canonical JSON profile with sorted keys, Unicode escape support,
duplicate/malformed-input rejection, 128-level nesting and one-million-value
ceilings, plus exact UTF-8, `u16`/`u32`/`i32` little-endian encode/read, and

writes never appear as artifacts. The frozen `forgepack` v1 layout and golden
archives are now the immediate capstone blockers.

## The critical-gap ranking (production-readiness assessment, 2026-07-05)

Honest answer given to "is it production-ready?": **no** — usable today for
typed polyglot orchestration and the agent-governance workflow; not yet for
large complex projects. Gaps, ranked by how hard they block "large & complex":

1. **Incomplete reusable/native abstraction path (`lang.4`)** — function
   values, generic functions, closures, effect-annotated `Fn` contracts,
   built-in `Eq` bounds, user-defined traits/impls, eligible private direct-call
   generic monomorphization, required methods, and checked interpreter trait
   dispatch, unique static C/Zig trait-call specialization, associated
   constants, and concrete associated-type bindings in trait contracts are
   shipped, along with coherent bounded generic/blanket impls. Default methods
   and generic impl associated items are also shipped with safe pure backing
   functions, concrete overrides, symbolic contract substitution, and unique
   native generic specialization. Standalone and bound-generic associated-type
   projections now validate and normalize recursively for interpreter and
   native-specialized use. Generic `Fn` binders preserve bounds and instantiate
   per indirect interpreter call. Monomorphic scalar named-function values and
   indirect calls now lower to C/Zig, including effect-annotated contracts whose
   effects otherwise satisfy the native function contract; runtime-only effects
   remain blocked at function level. Contextually typed non-capturing scalar
   closures are deterministically lifted into private functions for the same
   C/Zig ABI from annotated locals and their reassignments, direct statically
   known higher-order arguments, or typed `Fn` returns. Exported generic ABI policy, native generic function values,
   capturing and remaining-position closures, dynamic dispatch, and broader
   ambiguous specialization remain.
2. **Capsule call latency (`rt.3`)** — warm Python/Node/Go workers,
   auto-respawn, warm-by-default execution, dependency pipelines, and host-owned
   native compilation reuse are shipped. JVM/.NET warm workers remain;
   persistent native processes stay deferred until per-call budgets can be
   preserved.
3. **Fast path misses the useful language** — the v3.2 optimizer is live and
   trap-preserving; eligible generics, borrowed String inspection, and bounded
   fresh function-, nested branch-, loop-, or match-arm-local `Vec[T]` values for
   scalar primitives, bounded recursively fixed scalar/immutable-borrowed-view
   or declared-enum/named-struct-value arrays, borrowed immutable
   strings/scalar slices, declared enums, and backend-lowerable named structs
   now lower to C/Zig. Broader Vec ownership and remaining owned/generic elements,
   Map, owned String operations, capturing/remaining-position closures, and JIT remain.
4. **Safety claim not fully hardened (`safe.1`)** — the checker now has 40
   curated cases plus independent differential nets for 526 move programs and
   610 alias-reborrow programs covering descendant loans,
   shallow/nested/index projections, branch joins, loop-carried uses, and
   conditional joins inside loops and exhaustive two-, three-, and four-level
   nested-loop target joins, plus 292 lifetime-provenance programs with deep
   selective projection wrappers, projected recursive shapes, and generic
   wrappers composed with recursive collection carriers, 256 fixed seeded
   long-form properties, and a
   192-case default runtime-seeded campaign with bounded custom seeds, shrinking,
   replay artifacts, four checked-in rejection plus four acceptance regressions,
   and a weekly eight-seed
   4,608-case campaign that retains minimized failure files. All three fixed
   families now cover recursively normalized associated-type ownership shapes.
   A 38-case fourth fixed family covers affine `FnOnce` call/transfer state and
   mutable/shared direct/aliased capture roots. A balanced runtime affine family
   adds long call/transfer/spawn/reinitialization traces. Promotion of minimized
   failures remains when a campaign finds one; the expanded seed set found none.
5. **No real async scheduling/I/O** — deterministic cooperative tasks now include explicit parked-to-pending state, bounded typed deferred continuation chains, retry-safe polling, atomic wake-source rebinding, consuming logical-timer-aware task waits, bounded homogeneous task races with stable winner selection and loser cancellation, consuming logical deadlines with timeout cancellation, bounded shared one-shot event wakeups, deterministic nonblocking token selection, and bounded heterogeneous blocking/timeout waits over borrowed runnable-task, buffered-or-closed channel-read, open channel-send, capability-confined regular-file-read and no-clobber-create, and token arms; waits advance to the nearest represented logical timer or bounded deadline, preserve task/channel handles where contracted, preserve every observed source on heterogeneous timeout, and cancel task or token losers according to successful consuming operations. Pending logical timers support waiter-safe cancellation and same-clock rescheduling with fresh tie order; copyable fixed-rate intervals issue fresh catch-up-aware one-shot tick tokens and close without revoking issued ticks. Bounded structured task groups provide incremental ordered scheduler steps and FIFO backpressure; versioned transition receipts define the reference contract. Hosted I/O remains blocking and there are no worker threads, statement-frame suspension, OS/reactor wake sources, open-stream/socket readiness, active interruption, or wall-clock integration.
6. **Stdlib breadth** — no time, in-language JSON, regex; byte-only strings;
   no `?`-style error propagation.
7. **Dev loop at scale** — ~~no debugger~~ (v0 tracing debugger shipped
   2026-07-08, user-prioritized: `fgx debug` with canonical-node-id traces,
   breakpoints, trap post-mortems); still no profiler/REPL or package
   registry for Forgentex libraries.

Fix order chosen: **1 → 2 → 3 → 4 → 5**, stdlib continuously, capped by a
deliberately small `app.cap` to prove the composition honestly.

## Standing conventions (apply to every slice)

- **Slice discipline:** parser (both syntaxes) → formatter (dense `.fgai`
  keyword) → typecheck → interpreter → CFG/borrow soundness → C/Zig (lower or
  honestly contract-block) → tests → docs → full gate → commit.
- **Full gate:** `cargo test` + `cargo fmt` + `cargo clippy --all-targets -- -D
  warnings` + `fgx release-check --target v1.0 --strict` (exit 0).
- **Honesty rules:** never claim verified what didn't run here (e.g. .NET);
  backends must *reject* what they can't lower rather than miscompile; every
  new construct must be modeled in the CFG or the borrow checker is unsound.
